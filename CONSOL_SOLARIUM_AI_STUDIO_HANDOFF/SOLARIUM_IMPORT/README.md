# Opal Light Box

A standalone site containing the original scanned opal, its green/blue optical response, and one adjustable lamp. Includes lamp azimuth, elevation, brightness, fill light, background, view reset, and drag/pinch camera controls.

## Deploy to Vercel

Unzip this package. Use the `opal-light-box-site` directory as the project root.

With the Vercel CLI, run:

```sh
npx vercel --prod
```

Sign in to your Vercel account and follow the prompts. The included `vercel.json` sets the framework to Other, the build command to `npm run build`, and the output directory to `dist`.

Alternatively, add this directory's contents to your own Git repository and import that repository into Vercel. No secrets, API keys, database, or GitHub connection to ChatGPT are required by the site.

Vercel configuration reference: https://vercel.com/docs/project-configuration/vercel-json
CLI reference: https://vercel.com/docs/cli/deploy

## Use the ready-built site

The `dist` folder is complete and ready to serve from the root of any static web host. It includes the stone, optical maps, and local Draco decoder. Upload the contents of `dist`, preserving its directory structure. Opening index.html directly as a local file will not load the 3D assets; use an HTTP server.

## Build and preview locally

Use Node.js 20 or newer:

```sh
npm ci
npm run build
npm run preview
```

Open http://localhost:3000. The preview server is local only.

## Files

- `src/App.tsx`: light-box controls and page.
- `src/ThreeOpalViewer.tsx`: renderer and optical shader.
- `src/style.css`: responsive layout.
- `public/models`: original scanned GLB plus smoothed optical maps.
- `public/draco`: local geometry decoder.
- `public/index.html`: page metadata and icon.
- `dist`: tested production build, also regenerated by `npm run build`.
- `vercel.json`: Vercel deployment configuration.
- `netlify.toml`: optional Netlify deployment configuration.

## Behaviour and scope

The original scanned geometry is preserved. The smoother optical maps are a visual approximation based on the original maps; this is a visual lighting study, not a scientifically calibrated measurement system. The flash depends on lamp direction and brightness. Fill light illuminates the base material independently. The opening view uses the original fitted stone pose and lamp direction.

Browser requirements: WebGL 2 and JavaScript. All model and decoder files are served locally by the deployed site. The package has no ChatGPT hosting dependency and does not change the original altmook repository or deployment.
