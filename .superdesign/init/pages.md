# Pages — dependency trees
Project: vanilla HTML/CSS/JS single-page app (no framework, no build, no Tailwind). Markup is generated by template-literal functions in `app.js`; all styling is global CSS in `styles.css` (dark glass theme, see theme.md). Hash router (`#/home`, `#/samples/AND-000001`). Data from Supabase.

Every page is an async function in `app.js` returning an HTML string; trees list the functions, data calls and CSS involved. All pages also depend on `ensureShell`, `render`, `header`, `esc`, and `styles.css`.

## #/home — `pageHome`
- data: `api.counts`, `api.overview({limit:5})`, `signed()` (thumbnail URLs)
- `header`, `newSampleBtn`
  - `sampleRow`
- CSS: `.grid` `.card.hero` `.hero-inner` `.stats` `.stat` `.pill` `.sample-list`

## #/samples — `pageSamples`
- data: `api.overview()`, `signed()`
- `header`, `newSampleBtn`, `sampleRow`, `emptyBox`

## #/samples/<ID> — `pageSample` → `sampleHTML`
- data: `api.sampleDetail` (samples, sample_images, analyses, sample_events), `signed()`
- `header` (+ Attach pXRF → `openImport`)
- `.photo-card` (cover `<img>` or decorative orb), `.detail`, `.tabs`
- `tabBody` per tab
  - Overview: `.fields`, `elementGrid` (latest reading), `emptyAnalysis`
  - Evidence: `.tab-actions` (Add photo → `addPhotosToSample` → `uploadPhoto`), `.gallery` `.tile`
  - Analysis: `.chips` `.chip` (readings), `elementGrid`
  - History: `.events` `.event`, `eventDetail`, `EVENT_LABEL`

## #/analysis — `pageAnalysis`
- data: `api.overview({analysed:true})`
- `header` + Import Vanta CSV → `openImport` → `pickCsv` → `buildPlan` (`Vanta.parse`, `api.knownIds`) → `planSummary` → `runImport` (`api.addAnalyses`)
- `sampleRow`

## #/provenance — `pageProvenance`
- data: `api.events`
- `.events` `button.event`

## #/settings — `pageSettings`
- `.card.pad` `.fields`, Sign out

## Modal: New sample — `openNewSample`
- `openModal`, camera: `startCamera` `capturePhoto` `stopCamera`, `renderShots`, `addShot`, `validatePhoto`
- `saveSample` → `api.addSample` → `uploadPhoto` (`makeThumb`, `sha256Hex`, Storage upload, `sample_images` insert)

## Auth screens — `showLogin`, `showSetup`, `showPending`, `showFatal`, `showBooting` (all via `authScreen`)

Files: `index.html`, `config.js`, `vanta.js` (CSV parser), `app.js`, `styles.css`.
