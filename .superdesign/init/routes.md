# Routes
Project: vanilla HTML/CSS/JS single-page app (no framework, no build, no Tailwind). Markup is generated by template-literal functions in `app.js`; all styling is global CSS in `styles.css` (dark glass theme, see theme.md). Hash router (`#/home`, `#/samples/AND-000001`). Data from Supabase.

Hash-based routing. All routes except the auth screens render inside the app shell. Not signed in → sign-in screen; signed in but not on `staff` → "Access not granted"; schema missing → "Database not set up yet".

| Hash | Page function | Nav item | Shows |
| --- | --- | --- | --- |
| `#/home` (default) | `pageHome` | Home | Hero + counts (samples / analysed / photographed) + 5 recent specimens |
| `#/samples` | `pageSamples` | Samples | List of all samples with thumbnails + New sample |
| `#/samples/<ID>` | `pageSample` | Samples | Sample record: cover photo, tabs Overview / Evidence / Analysis / History, Attach pXRF |
| `#/analysis` | `pageAnalysis` | Analysis | Samples that have readings + Import Vanta CSV (bulk, matched by ID in each row) |
| `#/provenance` | `pageProvenance` | Provenance | Feed of the latest 100 events across all samples |
| `#/settings` | `pageSettings` | Settings | Signed-in email, database host, Sign out |

Modals (not routes): New sample (camera/photo + fields), Import Vanta export.

### Router
```js
const pages = { home: pageHome, samples: pageSamples, sample: pageSample, analysis: pageAnalysis, provenance: pageProvenance, settings: pageSettings };

function parseRoute() {
  const parts = location.hash.replace(/^#\/?/, '').split('/').filter(Boolean);
  const page = parts[0] === 'samples' && parts[1] ? 'sample' : (parts[0] || 'home');
  return { page: pages[page] ? page : 'home', id: parts[1] ? decodeURIComponent(parts[1]) : null };
}

const go = hash => { if (location.hash === hash) render(); else location.hash = hash; };
```
