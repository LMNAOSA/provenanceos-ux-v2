# Extractable components
Project: vanilla HTML/CSS/JS single-page app (no framework, no build, no Tailwind). Markup is generated by template-literal functions in `app.js`; all styling is global CSS in `styles.css` (dark glass theme, see theme.md). Hash router (`#/home`, `#/samples/AND-000001`). Data from Supabase.

Template functions in `app.js` that map to reusable components. (No per-file source paths exist beyond `app.js`; source for each is in components.md / layouts.md.)

## Layout Components

## NavRail
- Source: `app.js` → `ensureShell` (`.rail`, `.brand`, `.system`, `.nav`)
- Category: layout
- Description: Left rail (top bar on mobile) with APP logo, ProvenanceOS mark and 5 nav items
- Extractable props: activeItem (string, default: "home")
- Hardcoded: logos, nav labels (Home, Samples, Analysis, Provenance, Settings), all CSS

## PageHeader
- Source: `app.js` → `header`
- Category: layout
- Description: Eyebrow + large light title + optional subtitle on the left, optional primary action on the right
- Extractable props: eyebrow (string), title (string/html), subtitle (string), actionLabel (string)
- Hardcoded: typography, spacing, button style

## AuthCard
- Source: `app.js` → `brandBlock`, `authScreen`
- Category: layout
- Description: Centred glass card with brand block, used for sign-in, setup, and status screens
- Extractable props: eyebrow (string), title (string), message (string), primaryLabel (string)
- Hardcoded: logos, card styling

## Basic Components

## SampleRow
- Source: `app.js` → `sampleRow`
- Category: basic
- Description: Pill-shaped list row: thumbnail, sample ID, type · location, status label
- Extractable props: id (string), type (string), location (string), status ("Registered" | "Analysed"), thumbUrl (string)
- Hardcoded: chevron, layout, CSS

## StatTile
- Source: `app.js` → `pageHome` (`.stat`)
- Category: basic
- Description: Number over a tiny uppercase caption
- Extractable props: value (number), label (string)
- Hardcoded: styling

## ElementCard
- Source: `app.js` → `elementGrid` (`.element`)
- Category: basic
- Description: One pXRF element: symbol, big value, unit · ± error; muted "<LOD" variant
- Extractable props: symbol (string), value (number|null), unit (string), error (number), belowDetection (boolean)
- Hardcoded: number formatting, CSS

## TabBar
- Source: `app.js` → `sampleHTML` (`.tabs`)
- Category: basic
- Description: Underlined text tabs (Overview, Evidence, Analysis, History)
- Extractable props: activeTab (string)
- Hardcoded: tab labels, CSS

## Modal
- Source: `app.js` → `openNewSample` / `openImport` (`.modal` `.modal-box`)
- Category: basic
- Description: Blurred backdrop with rounded glass dialog, header with close button, `.actions` footer
- Extractable props: eyebrow (string), title (string), subtitle (string)
- Hardcoded: close button, footer button style
